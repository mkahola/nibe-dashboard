Connect to myUplink API

Enter your myUplink application credentials to connect. Data is fetched directly from Nibe's cloud — no local hardware required.

First time? Register a free API application:
1. Sign in at myuplink.com and link your pump
2. Go to dev.myuplink.com/apps → Create Application
3. Set Callback URL to exactly:
4. Paste the Client ID and Client Secret below
Credentials are stored only in your browser's localStorage and never sent anywhere except to api.myuplink.com. Use HTTPS.

Paste the authorization code

A browser tab opened the myUplink authorization page. After you approve access, myUplink redirects you back here with a code in the URL — or you can copy it from the redirect URL bar.
